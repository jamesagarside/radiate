No one can sign in yet. Add the first person where Radiate runs, with the same --config or --data-dir as the server:

radiate users add NAME --role admin --config radiate.yaml

This page never creates the first account, so whoever reaches it first can't take over the heating.

Forgotten your password? Whoever runs Radiate can reset it with radiate users reset-password.
