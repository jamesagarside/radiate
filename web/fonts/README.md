# Fonts

Served with the web UI so the page makes no requests outside the Radiate server.
Latin subsets, from the Fontsource packages (`@fontsource/funnel-display`,
`@fontsource/funnel-sans`, version 5).

|---|---|---|

| Funnel Sans 400, 500, 600 | Body text | SIL Open Font License 1.1, `OFL-Funnel.txt` |
