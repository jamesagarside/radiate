# Fonts

Served with the web UI so the page makes no requests outside the Radiate server.
Latin subsets, from the Fontsource packages (`@fontsource/doto`,
`@fontsource/funnel-display`, `@fontsource/funnel-sans`, version 5).

| Font | Use | Licence |
|---|---|---|
| Doto 700, 900 | Readouts: temperatures, counts, times | SIL Open Font License 1.1, `OFL-Doto.txt` |
| Funnel Display 600, 700 | Headings and the wordmark | SIL Open Font License 1.1, `OFL-Funnel.txt` |
| Funnel Sans 400, 500, 600 | Body text | SIL Open Font License 1.1, `OFL-Funnel.txt` |
